Part 2:

**Branch** - A branch is a place separate from your master line of code where you can edit the code, which won't affect the main repository until you merge it then the changes are added
**Clone** - Clone is when you grab a copy of the repository and put it in your local device
**Commit** - A commit is a snapshot of the changes you made in the repository where youu can put messages of what that commit was and dial back on it later if you want.
**Fetch** - A fetch allows you to see the recent changes others have done in your repository without applying any of your own changes. 
**GIT** - Git allows for connectivity to github via a CLI to upload, clone, change, or overall manage repositories via https, ssh, etc.
**Github** - Github is a cloud-based web application that allows for users to share/develop private or public repositories. 
**Merge** - Merge is used when you want to merge the code you have done from a separate branch to the main repository  
**Merge Conflict** - Usually happens when 2 edits conflict with each other and a merge is unable to happen
**Push** - Push is used to upload local commits to github
**Pull** - Grabs the changes from your remote repository and immediately merges them into your local branch.
**Remote** - Remote in github terms means it is hosted outside of your local device i.e github repositories.
**Repository** - It is a series of files, commits, and branches that are filed into one, usually stored in a cloud-based web like github.
